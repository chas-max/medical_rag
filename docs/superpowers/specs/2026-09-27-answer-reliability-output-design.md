# 问答可靠性与精简展示设计

**日期：**2026-09-27

**状态：**方案 2 已选定，待本文档审阅

## 目标与依据

修复公开医疗资料问答中模型选择与配置不一致所造成的失败，让模型或工作流故障以安全、可理解的方式呈现；同时让用户优先看到简洁、可核对的答案，而不是内部运行信息。本设计沿用已提交的 [Qwen-only provider 设计](2026-09-27-qwen-only-provider-design.md)，不另设第二套 provider 规则。

当前聊天页、工作流编辑器以及后端默认值仍会选择 DeepSeek；若部署只配置 Qwen，生成前就会因缺少 DeepSeek 密钥失败。工作流路由即使节点失败也可能以 HTTP 200 返回 `status: failed`，聊天页目前将失败文字当作助手回答展示。正常回答则直接显示 `[chunk_id]` 和运行 ID，引用资料与常用设置也占据较多空间。工作区已有调用超时、离线重排、引文容错等未提交修复；实施时须在其基础上工作，不覆盖或顺手重写。

## 方案与边界

保持现有 `/answers` 的 `{answer, citations, abstained}` 和工作流运行结果结构，不重做 API 契约。统一配置、入口默认值和调用方为 Qwen；从 API、工作流输入和离线评估入口拒绝显式 `deepseek`，不静默替换模型。聊天页不再显示模型选择，工作流编辑器的试运行固定使用 Qwen；运行时仍通过已有环境配置取得 Qwen 模型、地址和密钥，不读取、修改或删除 `.env`。

问答页默认只展示对话、连接状态与必要的来源入口；将工作流及证据数选择移入默认收起的“高级设置”，保留当前默认工作流 `medical-answer` 和默认证据数 5。隐藏聊天回答中的运行 ID，但保留工作流编辑器里的运行追踪。编辑器仍负责技术诊断，不把节点轨迹铺在普通聊天视图。

## 生成与校验

生成器继续只向模型发送问题和检索证据，并要求返回受限 JSON：每条事实结论须附原文引用。提示词要求先回答问题的核心，再给出必要条件、数值或例外；优先 3–5 条、不重复、不添加证据之外的医学建议，最多维持现有 8 条上限。回答不足时允许空 `claims`，不强行凑数或显示套话。

引文校验仍为发布前的强制边界：只接受本次检索块中的可验证原文，沿用当前工作区已加入的空白差异容忍和逐条过滤；一条不可信结论不得污染其余已核对结论。若没有可核对的结论，保持现有安全拒答，不显示模型原文、未验证结论或检索全文。模型服务不可用时不回退到另一模型，也不把检索片段伪装成回答。

传输层将已知的密钥缺失、认证/权限、限流、连接/超时和其他上游状态错误映射为稳定的安全错误码与简短中文提示。不能把上游原始错误体、密钥、请求头或模型草稿传到客户端。`/answers` 保持统一错误 envelope；工作流运行接口保持现有“运行结果内 `status: failed`”契约，聊天页必须检查该状态，并将失败显示为错误提示，而非成功的助手消息。证据不足的拒答与服务故障在界面上有不同状态。

## 回答与引用展示

后端保留已验证的纯文本 `answer` 与 `citations` 数据，避免破坏现有 API 和评测调用方。聊天页只对助手的已核对回答做安全的文本拆分：按结论分行并留出段落间距；依据引用数组的 `chunk_id` 顺序，将行内 `[chunk_id]` 映射为紧凑的 `[1]`、`[2]` 等可点击来源标记。相同来源始终使用同一编号，标记指向现有来源抽屉。来源列表只显示文件名与页码；原文摘录在打开来源时显示，块 ID 不出现在普通界面。

不把回答当 HTML 或任意 Markdown 执行。历史本地会话可能没有完整引用元数据；对此原样、安全地显示文本，不丢失回答，也不改写 `localStorage`。拒答与错误提示不渲染虚假的引文。移动端保持可读间距和可点击目标，引用按钮应有可辨识的无障碍标签。

## 验收与测试

- 仅配置 Qwen 的部署中，聊天页、`/answers` 和工作流试运行都选择 Qwen；显式 DeepSeek 请求按现有错误规范拒绝。离线评估和现行使用文档与已提交的 Qwen-only 设计保持一致。
- 模拟模型认证、限流、超时和其他上游失败：回答不泄露原始异常；聊天页显示失败提示，不出现伪装成答案的助手消息，也不误标“证据不足”。
- 模拟正常 JSON、部分无效引文及完全无可用引文：仅展示验证后的事实；无有效事实时拒答；现有安全校验不退化。
- 前端测试覆盖分点排版、引用编号/抽屉、无技术性块 ID 和运行 ID、默认折叠的高级设置、旧会话兼容与运行失败状态。
- 新行为先写失败测试再实现；完成后运行相关 Python、前端测试及 lint/build。默认自动测试不得调用付费模型 API；真实 Qwen 连通性须在有凭据的环境单独验证。

## 非目标

不改变 Milvus 存储、向量检索、知识库资料、现有工作流 DAG 形状或医学事实判定标准；不加入新模型、新 UI 框架或富文本执行能力。不修改用户的 `.env`、已有未提交代码与测试中无关的部分，也不恢复已删除的 `.env.example`。
